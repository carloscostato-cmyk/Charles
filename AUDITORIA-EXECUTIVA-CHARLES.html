Charles - Assistente Virtual com Sincronização Labial

Introdução

Charles é um assistente virtual corporativo desenvolvido pela Claro Empresas para o Departamento de Data Center. Este documento descreve as funcionalidades multimodais do sistema, incluindo a nova funcionalidade de sincronização labial (lip-sync).

Recursos Gerais

  • Sintese de fala (Text-to-Speech) usando Web Speech API nativa
  • Reconhecimento de voz (Speech-to-Text)
  • Integração com RAG (Retrieval Augmented Generation)
  • Streaming de respostas token-by-token via SSE
  • **Sincronização labial (Lip-sync)** - Nova funcionalidade

Sincronização Labial (Lip-sync)

A funcionalidade de sincronização labial faz com que o avatar do Charles mova seus "lábios" (visemes) em sincronia com a fala gerada pelo sistema de TTS (Text-to-Speech). Isso cria uma experiência mais natural e humana, onde o movimento da boca corresponde aos fonemas sendo pronunciados.

Como funciona:

  1. Quando o Charles começa a falar, o sistema TTS dispara um evento tts:start
  2. O frontend processa o texto gerado, mapeando cada fonema para uma forma de boca (viseme)
  3. 19 elementos visuais no avatar representam diferentes configurações de boca:
    • Fonemas abertos: a, e, i, o, u
    • Fonemas fechados: m, n, l, s, r
    • Fonemas labiais: f, v, b, p
    • Fonemas complexos: sh, ch, lh, nh, j, g, k
  4. Cada viseme é exibido por 30ms, criando uma animação sequencial suave
  5. Quando o TTS termina, o evento tts:end limpa todos os visemes

Fonemas Suportados:

Fonema Viseme Descrição
'a' mouth-viseme-a Abertura ampla da boca
'e' mouth-viseme-e Média abertura, língua avançada
'i' mouth-viseme-i Boca quase fechada, sorriso
'o' mouth-viseme-o Boca redonda
'u' mouth-viseme-u Boc circular para som nasal
'm', 'p' mouth-viseme-m Lábios fechados, som nasal/bilabial
'f', 'v' mouth-viseme-f Lábios levemente separados, dentais
's', 'z' mouth-viseme-s Língua próxima ao palato, sibilante
'sh' mouth-viseme-sh Sibilante postalveolar (ch like em "shoe")
'ch' mouth-viseme-ch Africativa postalveolar
'j' mouth-viseme-j Som de "dj" como em "joio"
'r' mouth-viseme-r Rolado ou approximante alveolar
'l', 'n' mouth-viseme-l Lateral ou nasal
'g', 'k' mouth-viseme-g Parada velar, fundo da boca

Integração com TTS:

O lip-sync está integrado ao módulo de síntese de fala em frontend/js/voice.js. O sistema dispatches os seguintes eventos CustomEvent:

  • tts:start - Dispatchado quando a fala começa
  • tts:end - Dispatchado quando a fala termina
  • tts:error - Dispatchado em caso de erro na síntese

No frontend/js/app.js, listeners capturam esses eventos e controlam a animação dos visemes correspondente.

Benefícios da Sincronização Labial

  • Experiência mais envolvente e natural para o usuário
  • Melhor compreensão da entonação e ritmo da fala
  • Acessibilidade aprimorada para usuários com deficiência auditiva (feedback visual)
  • Professional appearance for corporate communications
  • Feedback visual que confirma que o sistema está "falando"

Configuração

A sincronização labial está habilitada por padrão e requer:

  • Navegador compatível com Web Speech API (Chrome, Edge)
  • Voices disponíveis no sistema (já configurado no VoiceSynthesis class)
  • Nenhuma chave de API externa - usa a API nativa do navegador
